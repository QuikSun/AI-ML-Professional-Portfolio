    What each network learns from

    Feedforward artificial neural network (ANN)
    A dense network combines encoded word cues. Here the next word in the text supplies the target.
    Convolutional neural network (CNN)
    A shared filter scans short word windows. The same next-word objective can teach the network which local patterns help its prediction.
    Recurrent neural network (RNN)
    A hidden state carries context forward as the network reads. The next word supplies the target here as well.
    Generative adversarial network (GAN)
    A generator proposes text. A discriminator learns to distinguish corpus examples from generated ones, and its score guides the generator.

    The first three demos use self-supervised learning. During training, the text supplies the next word as the target. During generation, the model scores possible continuations from the prompt. The GAN uses adversarial training and can combine an RNN generator with a CNN discriminator. Many modern language models use a Transformer to predict the next token.
