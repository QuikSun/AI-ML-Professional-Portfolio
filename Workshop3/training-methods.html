Workshop notes and sources

The case decisions adapt the fraud, segmentation, and maze scenarios from 3.3 AI Training Interaction. The weight update and network examples apply 3.2 Neural Networks. The survey panel challenge uses fictional records and simulated feedback.

A training method describes what the model learns from, such as labels or rewards. A network architecture describes how the model processes its inputs. One architecture can learn from different kinds of feedback.

Artificial neural network (ANN)
Connected units use weights and activation functions to transform inputs. Training updates the weights to improve the model against its objective.
Convolutional neural network (CNN)
A filter can look for the same local pattern across an image, such as an edge in a survey screenshot.
Recurrent neural network (RNN)
A model can carry information from one step of an ordered sequence to the next, as in the panel example.
Generative adversarial network (GAN)
A generator makes synthetic examples and a discriminator learns to distinguish generated examples from real ones. Before using generated survey data for reporting, check whether it represents the groups and patterns the report needs.
